# Reese Bowling

Personal portfolio site for Reese Bowling, a data and analytics professional with a background in forensic investigations, financial crime analytics, and enterprise data platforms. Built as a custom, framework-free static site (HTML, CSS, and vanilla JavaScript), no build tooling required.

## Structure

```
index.html              Homepage: hero, about, featured case studies, additional projects, skills, beyond the desk, contact
case-studies/*.html      Full write-ups for each featured and additional project
assets/css/style.css     Site styling
assets/js/main.js        Mobile navigation
assets/img/              Site imagery
assets/resume/           Downloadable resume
```

## A note on the case studies

All project write-ups are generalized to protect client confidentiality. Company and institution names are withheld throughout and engagements are described by industry, role, and scope instead.

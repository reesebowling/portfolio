Advertising Data Copyright Infringement Analysis

Large-scale advertising data processing and fuzzy-matching analysis supporting an expert witness engagement in a copyright infringement case.

DatabricksPythonSQLAWS S3Fuzzy Matching

Note: client and institution names are withheld per confidentiality requirements. This engagement is described using generalized role and industry context only.

The Challenge

An expert witness engagement required large-scale advertising data processing for a major technology company, supporting a copyright infringement analysis that depended on identifying infringing URLs buried in unstructured advertising records.

The Approach

  • Built an automated ETL pipeline leveraging AWS S3 and Databricks to ingest and process large volumes of advertising data, including ad records, merchant attributes, impressions, and click data.
  • Transformed a semi-structured single-text field containing compound advertising attributes into a structured analytical dataset, enabling systematic analysis across previously unstructured records.
  • Implemented fuzzy matching and keyword search logic in Python to identify infringing URLs across the advertising dataset, surfacing matches that exact-string methods would have missed.
  • Leveraged an in-house AI tool to optimize data lineage tracking and strengthen controls across data files, improving traceability and auditability of analytical outputs.
Fuzzy matching surfaced infringing URLs buried in unstructured ad data that exact-match methods would have missed entirely.

The Impact

  • Delivered a structured, analysis-ready dataset from raw semi-structured advertising data, enabling the expert witness to perform systematic URL-level infringement analysis at scale.
  • Fuzzy matching and keyword logic surfaced infringing URLs that would have been undetectable through traditional exact-match approaches, materially expanding the scope of identified infringement.
  • Improved data lineage and auditability across the engagement through AI-assisted controls, producing a defensible analytical record suitable for expert report and potential litigation use.
